# 品番（partNumber）採番ルール — 商品登録エージェント向け

このドキュメントは、在庫管理システム（テナント: gunpla-list「プラモデル管理」など）に
**新しい商品（パーツ）を登録するときの品番の付け方**を定めたものです。
登録作業を行うエージェントは、必ずこのルールに従って品番を決めてください。

---

## 1. 大原則

**1商品 = 1つのユニークな品番。** 別の商品に同じ品番を付けてはいけません。

在庫はこの品番（partNumber）を単位に管理されます。もし違う商品に同じ品番を付けると、
それらの商品が在庫を共有してしまい、棚卸しやダッシュボードの在庫数がおかしくなります。

---

## 2. 品番の形式

```
品番 = 「ジャンル名」-「ユニットコード」-「末番号」
```

- すべて**大文字**、区切りは**半角ハイフン `-`**。
- 例:
  - `HG-G-WITCH-1`   （HGジャンル / 水星の魔女ユニット / 1番）
  - `HG-SEED-FREEDOM-3` （HG / SEED FREEDOM / 3番 → HGマイティーストライク）
  - `RG-CCA-5`   （RG / 逆襲のシャア / 5番）
  - `RG-UC-1`    （RG / ユニコーン / 1番）

### 各パーツの意味

| パーツ | 内容 | 例 |
|---|---|---|
| ジャンル名 | そのジャンルの略称（大文字） | `HG`, `RG`, `MGSD`, `PG` |
| ユニットコード | ユニットの短縮コード（大文字） | `SEED-FREEDOM`, `G-WITCH`, `CCA`, `UC` |
| 末番号 | そのユニット内での通し番号（1から連番） | `1`, `2`, `3`, ... |

---

## 3. ユニットコードの決め方

ユニットコードは、システム内部でユニットごとに割り当てられている短縮コード
（`parts.unitNumber` に相当）を**大文字化**して使います。既存ユニットのコードは以下のとおり。

### 新しいユニットを作る場合
- ユニット名を分かりやすく短縮し、**英大文字・数字・ハイフン**で表す。
- スペースはハイフンに変換（例: `SEED FREEDOM` → `SEED-FREEDOM`）。
- 作品の通称・略称があればそれを優先（例: 逆襲のシャア → `CCA`）。
- **同じジャンル内で他のユニットコードと重複しないこと。**

### 新しいジャンルを作る場合（MGSD, PG など）
- 同じルールをそのまま適用。例: `MGSD-SEED-FREEDOM-1`, `PG-UC-1`。
- ジャンル名の略称を大文字で先頭に付ける。

---

## 4. 末番号の決め方

- そのユニット内で、**1 から始まる連番**を順に振る。
- 既にそのユニットに商品がある場合は、**そのユニットの最大末番号 + 1** を使う。
  - 例: `HG-G-WITCH` に既に 1〜42 が存在 → 新商品は `HG-G-WITCH-43`。
- 欠番があっても詰め直さず、単純に最大+1で追加してよい。

---

## 5. やってはいけないこと（重要）

- ❌ 違う商品に同じ品番を付ける（在庫共有事故の原因）。
- ❌ 数字のみの品番（`1`, `2` など）を新規に付ける。必ずジャンル-ユニット-末番号の形にする。
- ❌ ユニットコードを既存と別表記にする（例: `SEED-FREEDOM` を `SEEDFREEDOM` にするなど揺れさせない）。
- ❌ カテゴリーを跨いで同じ品番を使い回す。

> 補足: システム内部の在庫は「カテゴリー × 品番」で一意管理されるため、
> 厳密には別カテゴリーなら同一品番でも衝突しません。しかし運用の混乱を避けるため、
> **品番はジャンル-ユニット-末番号で常にグローバルに一意**にしておくのが安全です。

---

## 6. 登録時のチェックリスト

1. その商品が属する **ジャンル** と **ユニット** を確認する。
2. ユニットの **ユニットコード**（本書 3章の表、または既存商品の品番から逆算）を確認する。
3. そのユニットの **既存の最大末番号 + 1** を末番号にする。
4. `ジャンル-ユニットコード-末番号`（すべて大文字）で品番を組み立てる。
5. 同じ品番が既に存在しないことを確認してから登録する。
